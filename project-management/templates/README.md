## قوالب Excel

### قالب استيراد المنتجات

**الاستخدام:** لاستيراد منتجات التاجر بشكل مجمع

**الأعمدة:**

| العمود         | الوصف                 | مثال                       | مطلوب |
| -------------- | --------------------- | -------------------------- | ----- |
| name_ar        | اسم المنتج بالعربي    | برجر لحم                   | ✅    |
| name_en        | اسم المنتج بالإنجليزي | Beef Burger                | ❌    |
| category_ar    | الفئة بالعربي         | برجر                       | ✅    |
| category_en    | الفئة بالإنجليزي      | Burgers                    | ❌    |
| price          | السعر                 | 85                         | ✅    |
| original_price | السعر الأصلي (للخصم)  | 100                        | ❌    |
| pricing_type   | نوع التسعير           | fixed                      | ✅    |
| description_ar | الوصف بالعربي         | برجر لحم مع جبنة           | ❌    |
| variants       | المتغيرات             | نصف كيلو:480\|ربع كيلو:250 | ❌    |
| image_url      | رابط الصورة           | https://...                | ❌    |
| is_available   | متاح                  | TRUE                       | ❌    |

**أنواع التسعير:**

- `fixed` - سعر ثابت
- `per_unit` - بالوحدة
- `variants` - متغيرات (أحجام)
- `weight_variants` - متغيرات بالوزن

**مثال:**

```csv
name_ar,name_en,category_ar,price,pricing_type,variants
برجر لحم,Beef Burger,برجر,85,fixed,
فراخ مشوية,Grilled Chicken,مشويات,120,variants,نصف:120|ربع:70
تفاح,Apples,فواكه,50,per_unit,
```

## قالب العرض التقديمي للتاجر

### الشريحة 1: الغلاف

```
إنجزنا
منصة التوصيل الأذكى في مصر

[شعار إنجزنا]
```

### الشريحة 2: المشكلة

```
التحديات اللي بتواجهك:

❌ طلبات بتضيع على التليفون
❌ عمولات عالية (18-25%)
❌ رسوم تسجيل غالية (3,000 ج.م)
❌ عملاء مش بيوصلولك
```

### الشريحة 3: الحل

```
إنجزنا = الحل

✅ صفر رسوم تسجيل
✅ صفر عمولة أول 30 يوم
✅ 7% بس بعد كده (أقل عمولة في السوق)
✅ بتستخدم سائقك الخاص
```

### الشريحة 4: المقارنة

```
إنجزنا vs طلبات

| البند | طلبات | إنجزنا |
|-------|-------|--------|
| رسوم التسجيل | 3,000 ج.م | 0 ج.م ✅ |
| العمولة | 18-25% | 0-7% ✅ |
| أول 30 يوم | 18-25% | 0% ✅ |
| سائقك | محدود | متاح ✅ |
```

### الشريحة 5: التوفير

```
التوفير السنوي

(100 طلب/شهر × 300 ج.م متوسط)

مع طلبات: 75,000 ج.م/سنة ❌
مع إنجزنا: 23,100 ج.م/سنة ✅

التوفير: 51,900 ج.م 💰
```

## ملخص بالعربية

هذا الملف يوضح القوالب الجاهزة للاستخدام في منصة إنجزنا. النقاط الرئيسية:

**القوالب المتاحة:**

1. **قوالب Excel:**
   - قالب استيراد المنتجات
   - يدعم: اسم المنتج، الفئة، السعر، نوع التسعير، المتغيرات

2. **قوالب التقارير:**
   - التقرير الأسبوعي
   - يشمل: التجار، الطلبات، الدعم، التسويق، التحديات

3. **النماذج:**
   - نموذج تسجيل تاجر جديد
   - يشمل: بيانات المتجر، الموقع، التواصل، ساعات العمل، الوثائق

4. **قوالب العروض:**
   - عرض تقديمي للتاجر
   - يشمل: المشكلة، الحل، المقارنة، التوفير، CTA

**أنواع التسعير المدعومة:**

- fixed: سعر ثابت
- per_unit: بالوحدة
- variants: متغيرات (أحجام)
- weight_variants: متغيرات بالوزن

**الفئات المستهدفة:** المطاعم، الصيدليات، السوبر ماركت، الخضراوات والفاكهه، البن والحلويات
