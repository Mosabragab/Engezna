## أنواع الشراكات

### 1. المؤثرون (Influencers)

**الهدف:** زيادة الوعي بالعلامة التجارية وجذب العملاء

#### معايير اختيار المؤثر

| المعيار      | الحد الأدنى            |
| ------------ | ---------------------- |
| المتابعون    | 5,000+                 |
| معدل التفاعل | ≥ 3%                   |
| الموقع       | نفس المحافظة المستهدفة |
| المحتوى      | مناسب للعلامة التجارية |
| السمعة       | جيدة، بدون جدل         |

#### أنواع التعاون

| النوع         | الوصف              | التكلفة المتوقعة    |
| ------------- | ------------------ | ------------------- |
| منشور واحد    | صورة أو فيديو قصير | 500-2,000 ج.م       |
| سلسلة منشورات | 3-5 منشورات        | 1,500-5,000 ج.م     |
| سفير العلامة  | تعاون شهري         | 3,000-8,000 ج.م/شهر |
| كود خصم       | عمولة على الطلبات  | % من المبيعات       |

#### قالب التواصل مع المؤثر

```
السلام عليكم [اسم المؤثر]،

أنا [الاسم] من إنجزنا - منصة التوصيل الجديدة في [المحافظة].

بنعجبنا محتواك جداً وشايفين إنك مناسب تكون جزء من قصتنا.

إنجزنا سوق إلكتروني بيربط المتاجر المحلية بالعملاء في المحافظات، وبنقدم أقل عمولة في السوق (7% بس).

نحب نتعاون معاك في [نوع التعاون].

لو مهتم، ممكن نتكلم في التفاصيل؟

شكراً 🙏
[الاسم]
[الوظيفة]
إنجزنا
```

### 2. غرف التجارة

**الهدف:** الوصول للتجار بشكل رسمي ومنظم

#### خطوات التعاون

```
1. تحديد غرفة التجارة المحلية
2. طلب موعد مع المسؤول
3. تقديم عرض رسمي عن المنصة
4. طلب:
   - قائمة بالتجار الأعضاء
   - إعلان في النشرة الدورية
   - ندوة تعريفية للتجار
5. تقديم عروض خاصة لأعضاء الغرفة
```

#### مميزات للتجار أعضاء غرفة التجارة

| الميزة         | التفاصيل                   |
| -------------- | -------------------------- |
| أولوية التسجيل | ضمان مكان في الموجة الأولى |
| دعم مخصص       | خط ساخن خاص                |
| تدريب جماعي    | ورش عمل مجانية             |

## ملخص بالعربية

هذا الملف يوضح إدارة الشراكات لمنصة إنجزنا. النقاط الرئيسية:

**أنواع الشراكات:**

1. **المؤثرون (Influencers):**
   - الهدف: زيادة الوعي بالعلامة التجارية
   - المعايير: 5,000+ متابع، 3%+ تفاعل، نفس المحافظة
   - التكلفة: 500-8,000 ج.م حسب نوع التعاون

2. **غرف التجارة:**
   - الهدف: الوصول للتجار بشكل رسمي

3. **الموردون والموزعون:**
   - الهدف: إحالة تجار جدد
   - أمثلة: موزعي المشروبات، موردي المطاعم

4. **الشراكات التقنية:**
   - Kashier: بوابة الدفع
   - HERE Maps: تحديد المواقع
   - Supabase: البنية التحتية

**ميزانية الشراكات:** 8,000 ج.م/شهر

- مؤثرون: 4,000 ج.م
- فعاليات: 2,000 ج.م
- مواد وهدايا: 2,000 ج.م

**الفئات المستهدفة:** المطاعم، الصيدليات، السوبر ماركت، الخضراوات والفاكهه، البن والحلويات، أكل بيتي
