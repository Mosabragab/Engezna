## سيناريوهات الدعم الشائعة

### 1. مشاكل التسجيل والدخول

**المشكلة:** التاجر لا يستطيع تسجيل الدخول

```
الخطوات:
1. التأكد من صحة رقم الهاتف/البريد
2. إرسال رابط إعادة تعيين كلمة المرور
3. التأكد من تفعيل الحساب
4. لو استمرت المشكلة → تصعيد للدعم التقني
```

**المشكلة:** التاجر لم يستلم OTP

```
الخطوات:
1. التأكد من صحة رقم الهاتف
2. الانتظار 60 ثانية وإعادة الإرسال
3. التحقق من عدم حظر الرقم
4. لو استمرت المشكلة → تصعيد
```

### 2. مشاكل الطلبات

**المشكلة:** التاجر لم يستقبل طلب

```
الخطوات:
1. التأكد من اتصال الإنترنت
2. تحديث صفحة الطلبات
3. التحقق من حالة المتجر (مفتوح/مغلق)
4. التحقق من ساعات العمل المحددة
5. مراجعة الطلب من لوحة الأدمن
```

**المشكلة:** العميل يشتكي من طلب

```
الخطوات:
1. الحصول على رقم الطلب
2. مراجعة تفاصيل الطلب
3. التواصل مع التاجر لفهم الموقف
4. تحديد المسؤولية (تاجر/توصيل/عميل)
5. اقتراح حل مناسب:
   - استرداد كامل
   - استرداد جزئي
   - إعادة الطلب
   - كوبون خصم
```

### 3. مشاكل المدفوعات والتسويات

**المشكلة:** التاجر يسأل عن التسوية

```
الخطوات:
1. مراجعة صفحة التسويات في لوحة التاجر
2. شرح فترة التسوية (أسبوعية)
3. شرح حساب العمولة
4. توضيح طرق الدفع المتاحة
```

**المشكلة:** اختلاف في مبلغ التسوية

```
الخطوات:
1. طلب تفاصيل الفترة المعنية
2. مراجعة الطلبات واحدة واحدة
3. التحقق من الطلبات الملغية
4. التحقق من المرتجعات
5. توضيح الحساب للتاجر
```

### 4. مشاكل تقنية

**المشكلة:** التطبيق بطيء أو لا يعمل

```
الخطوات:
1. التأكد من سرعة الإنترنت
2. مسح الكاش وإعادة تحميل
3. تحديث التطبيق (لو متاح)
4. تجربة من جهاز آخر
5. تصعيد للدعم التقني
```

## التصعيد

### متى نصعد؟

| الحالة                    | المستوى      |
| ------------------------- | ------------ |
| مشكلة لم تُحل خلال SLA    | مدير الفريق  |
| شكوى متكررة (3+ مرات)     | مدير الفريق  |
| مشكلة تقنية في المنصة     | الدعم التقني |
| نزاع مالي كبير (>500 ج.م) | الإدارة      |
| تهديد أو إساءة            | الإدارة      |

### إجراءات التصعيد

```
1. توثيق كل التفاصيل
2. إرفاق المحادثات السابقة
3. تحديد الأولوية
4. إرسال للمستوى الأعلى
5. إبلاغ العميل بالتصعيد
6. متابعة حتى الحل
```

## ملخص بالعربية

### النقاط الرئيسية

- **قنوات الدعم:**
  - WhatsApp Business: 8 ص - 10 م (SLA: 30 دقيقة)
  - الشات داخل التطبيق: 8 ص - 10 م (SLA: ساعتين)
  - الهاتف: 9 ص - 6 م (فوري)
  - زيارة ميدانية: حسب الموعد (24-48 ساعة)

- **تصنيف الأولوية:**
  - حرج: يمنع العمل تماماً (SLA: ≤ ساعة)
  - عالي: يؤثر على العمليات (SLA: ≤ 4 ساعات)
  - متوسط: إزعاج ولكن يمكن العمل (SLA: ≤ 24 ساعة)
  - منخفض: استفسار عام (SLA: ≤ 48 ساعة)

- **سيناريوهات الدعم الشائعة:**
  1. مشاكل التسجيل والدخول
  2. مشاكل الطلبات
  3. مشاكل المدفوعات والتسويات
  4. مشاكل تقنية

- **متى نصعد:**
  - مشكلة لم تُحل خلال SLA
  - شكوى متكررة 3+ مرات
  - مشكلة تقنية في المنصة
  - نزاع مالي كبير (>500 ج.م)
  - تهديد أو إساءة

- **الفئات المستهدفة:** المطاعم، الصيدليات، السوبر ماركت، الخضراوات والفاكهه، البن والحلويات، أكل بيتي
