# Quality Standards

## معايير الجودة لمنصة إنجزنا

**آخر تحديث:** يناير 2026

---

## معايير جودة التجار

### الحد الأدنى للقبول

| المعيار               | الحد الأدنى | ملاحظات        |
| --------------------- | ----------- | -------------- |
| تقييم عام             | ≥ 3.5/5     | بعد 10 طلبات   |
| نسبة قبول الطلبات     | ≥ 80%       | أسبوعياً       |
| نسبة الطلبات المكتملة | ≥ 90%       | شهرياً         |
| وقت الرد على الطلب    | ≤ 15 دقيقة  | 80% من الطلبات |
| شكاوى العملاء         | ≤ 10%       | من الطلبات     |

### معايير التميز (شارة الجودة)

| المعيار               | المستوى المطلوب |
| --------------------- | --------------- |
| تقييم عام             | ≥ 4.5/5         |
| نسبة قبول الطلبات     | ≥ 95%           |
| نسبة الطلبات المكتملة | ≥ 98%           |
| وقت الرد              | ≤ 5 دقائق       |
| شكاوى العملاء         | ≤ 2%            |
| عدد الطلبات           | ≥ 100 طلب/شهر   |

## إجراءات مراقبة الجودة

### المراجعة الأسبوعية

```
كل أسبوع:
□ مراجعة تقييمات التجار
□ تحديد التجار تحت المستوى المطلوب
□ التواصل مع التجار المتدنين
□ تقديم نصائح للتحسين
```

### المراجعة الشهرية

```
كل شهر:
□ تقرير أداء شامل للتجار
□ تحديد أفضل 10 تجار
□ تحديد أسوأ 10 تجار
□ خطة تحسين للتجار المتدنين
□ مكافآت للتجار المتميزين
```

## نظام الإنذارات

### مستويات الإنذار

| المستوى        | السبب                      | الإجراء             |
| -------------- | -------------------------- | ------------------- |
| **إنذار أول**  | تقييم < 3.5 أو شكاوى > 10% | تنبيه + نصائح       |
| **إنذار ثاني** | استمرار المشكلة أسبوعين    | اجتماع مع المندوب   |
| **إنذار ثالث** | استمرار المشكلة شهر        | تعليق مؤقت (7 أيام) |
| **إيقاف**      | عدم التحسن بعد التعليق     | إيقاف دائم          |

### أسباب الإيقاف الفوري

```
🔴 إيقاف فوري بدون إنذار:
• بيع منتجات مغشوشة أو فاسدة
• إساءة للعملاء
• عدم الالتزام بالأسعار المعلنة
• التلاعب في الطلبات
• انتهاك شروط الخدمة
```

## معايير المنتجات

### الصور

| المعيار | المطلوب               |
| ------- | --------------------- |
| الجودة  | واضحة، إضاءة جيدة     |
| الحجم   | ≥ 500×500 بكسل        |
| الخلفية | نظيفة، يفضل بيضاء     |
| المحتوى | المنتج فقط، بدون نصوص |

### الأوصاف

| المعيار | المطلوب                     |
| ------- | --------------------------- |
| اللغة   | عربي واضح (إنجليزي اختياري) |
| الطول   | 20-200 حرف                  |
| المحتوى | وصف دقيق للمنتج             |
| الأسعار | صحيحة ومحدثة                |

## معالجة الشكاوى

### تصنيف الشكاوى

| النوع         | الوصف                    | المسؤولية      |
| ------------- | ------------------------ | -------------- |
| جودة المنتج   | منتج فاسد/مختلف عن الوصف | التاجر         |
| تأخير التوصيل | تجاوز الوقت المتوقع      | التاجر (سائقه) |
| خطأ في الطلب  | نقص/زيادة في المنتجات    | التاجر         |
| مشكلة تقنية   | خلل في التطبيق           | إنجزنا         |
| سلوك غير لائق | إساءة من التاجر/السائق   | التاجر         |

### إجراءات التعويض

| نوع المشكلة           | التعويض                  |
| --------------------- | ------------------------ |
| منتج فاسد             | استرداد كامل + كوبون 10% |
| طلب ناقص              | استرداد قيمة الناقص      |
| تأخير كبير (> 1 ساعة) | كوبون 15%                |
| خطأ في الطلب          | استرداد/استبدال          |

## ملخص بالعربية

### النقاط الرئيسية

- **معايير الحد الأدنى للقبول:**
  - تقييم عام ≥ 3.5/5
  - نسبة قبول الطلبات ≥ 80%
  - نسبة الطلبات المكتملة ≥ 90%
  - وقت الرد ≤ 15 دقيقة
  - شكاوى العملاء ≤ 10%

- **معايير التميز (شارة الجودة):**
  - تقييم ≥ 4.5/5
  - قبول طلبات ≥ 95%
  - إكمال ≥ 98%
  - شكاوى ≤ 2%
  - ≥ 100 طلب شهرياً

- **نظام الإنذارات:**
  1. إنذار أول: تنبيه ونصائح
  2. إنذار ثاني: اجتماع مع المندوب
  3. إنذار ثالث: تعليق مؤقت 7 أيام
  4. إيقاف دائم عند عدم التحسن

- **أسباب الإيقاف الفوري:**
  - منتجات مغشوشة أو فاسدة
  - إساءة للعملاء
  - التلاعب في الأسعار أو الطلبات

- **إجراءات التعويض:**
  - منتج فاسد: استرداد كامل + كوبون 10%
  - طلب ناقص: استرداد قيمة الناقص
  - تأخير كبير: كوبون 15%

- **الفئات المستهدفة:** المطاعم، الصيدليات، السوبر ماركت، الخضراوات والفاكهه، البن والحلويات، أكل بيتي
