# Sales Script

## نص المبيعات الموحد لمندوبي إنجزنا

**آخر تحديث:** يناير 2026
**الإصدار:** 1.0

---

## قبل الزيارة

### التحضير

```
□ مراجعة معلومات التاجر (الاسم، النوع، الموقع)
□ تجهيز المواد (بروشور، بطاقة عمل، تابلت)
□ التأكد من معرفة العرض الحالي (الموجة)
□ تحديد الهدف من الزيارة
```

### المواد المطلوبة

- بروشور إنجزنا
- بطاقات عمل
- تابلت/موبايل لعرض التطبيق
- نموذج تسجيل (ورقي أو رقمي)

---

## مراحل المحادثة

### 1. التحية والتعريف (30 ثانية)

```
🗣️ النص:
"السلام عليكم، أنا [الاسم] من إنجزنا - منصة التوصيل الجديدة في بني سويف.
عندك دقيقتين أعرفك على عرض مميز جداً للتجار؟"

✅ نصائح:
• ابتسم وكن ودوداً
• تواصل بالعين
• لو مشغول، اسأل عن وقت أفضل للزيارة
```

### 2. فهم الوضع الحالي (1-2 دقيقة)

```
🗣️ الأسئلة:
"بتستقبل طلبات توصيل حالياً؟"
"بتستخدم تطبيق معين ولا تليفون؟"
"إيه أكتر مشكلة بتواجهك في الطلبات؟"

✅ استمع جيداً للإجابات
✅ دوّن الملاحظات المهمة
```

### 3. تقديم إنجزنا (2-3 دقائق)

```
🗣️ النص:
"إنجزنا سوق إلكتروني بيربط متجرك بالعملاء في المحافظة.
الفكرة إننا نساعدك تستقبل طلبات أكتر من غير ما تدفع فلوس كتير - وأنت بتستخدم سواقك الخاص."

🔥 النقاط الرئيسية:

1️⃣ صفر رسوم تسجيل
   "مفيش أي رسوم تسجيل - صفر جنيه."
   "طلبات بياخدوا 3,000 جنيه رسوم تسجيل، إحنا مجاناً."

2️⃣ صفر عمولة 30 يوم
   "أول 30 يوم العمولة صفر - كل اللي تبيعه ليك."
   "تخيل 30 يوم تجرب المنصة من غير ما تدفع حاجة!"

3️⃣ أقل عمولة في السوق
   "بعد 30 يوم، العمولة 7% بس."
   "طلبات بياخدوا 18-25%، إحنا 7% فقط!"

4️⃣ التوصيل بسائقك
   "بتستخدم سائقك الخاص - مفيش سائقين غرباء."
   "أنت متحكم في كل حاجة."
```

### 4. عرض الحساب (1-2 دقيقة)

```
🗣️ النص:
"خليني أحسبلك التوفير..."

📊 مثال (100 طلب/شهر، متوسط 300 ج.م):

┌─────────────────────────────────────────────────┐
│  مع طلبات (20% عمولة + 3,000 تسجيل):          │
│  • رسوم تسجيل: 3,000 ج.م                       │
│  • عمولة شهرية: 30,000 × 20% = 6,000 ج.م      │
│  • السنة الأولى: 75,000 ج.م ❌                 │
├─────────────────────────────────────────────────┤
│  مع إنجزنا (الموجة 1):                         │
│  • رسوم تسجيل: 0 ج.م                           │
│  • أول 30 يوم: 0 ج.م                           │
│  • 11 شهر × 7%: 23,100 ج.م                     │
│  • السنة الأولى: 23,100 ج.م ✅                 │
├─────────────────────────────────────────────────┤
│  💰 التوفير: 51,900 ج.م في السنة!              │
└─────────────────────────────────────────────────┘

🗣️ "يعني هتوفر أكتر من 50 ألف جنيه في السنة الأولى بس!"
```

### 5. عرض التطبيق (2-3 دقائق)

```
🗣️ النص:
"خليني أوريك التطبيق بسرعة..."

📱 اعرض:
1. واجهة العميل (كيف يطلب)
2. لوحة تحكم التاجر (كيف يستقبل الطلبات)
3. نظام التسعير (لو مناسب للتاجر)
4. الإشعارات والتنبيهات

✅ خلي التاجر يجرب بنفسه لو أمكن
```

### 6. التعامل مع الاعتراضات

#### "أنا مع طلبات بالفعل"

```
🗣️ الرد:
"ممتاز! كتير من التجار عندنا كانوا مع طلبات.
الفرق إنك هتوفر أكتر من 50 ألف جنيه في السنة.
وممكن تشتغل على الاتنين في البداية لحد ما تقارن بنفسك."
```

#### "التطبيق جديد ومفيش عملاء"

```
🗣️ الرد:
"صح، إحنا لسه بادئين. وعشان كده العرض ده للتجار الأوائل.
أول 30 تاجر في كل فئة بياخدوا صفر رسوم وصفر عمولة.
وإحنا بنعمل حملات تسويق قوية لجذب العملاء."
```

#### "مش عندي وقت"

```
🗣️ الرد:
"فاهم، أنت مشغول.
خليني أسيبلك البروشور، وأرجعلك بكره في وقت أنسب.
إيه أحسن وقت ليك؟"
```

#### "هفكر وأرد عليك"

```
🗣️ الرد:
"تمام، خد وقتك. بس خلي بالك إن عرض الموجة الأولى لأول 30 تاجر بس.
لما الأماكن تخلص، الرسوم هتبقى 2,000 جنيه.
ممكن أتصل بيك بكره أتأكد لو عندك أسئلة؟"
```

#### "العمولة 7% كتير"

```
🗣️ الرد:
"7% دي أقل عمولة في السوق كله!
طلبات بياخدوا 18-25%، يعني 3 أضعاف.
وأول 30 يوم صفر عمولة - يعني بتجرب ببلاش."
```

### 7. إتمام الصفقة

```
🗣️ النص (لو مهتم):
"تمام، يلا نسجلك دلوقتي عشان تلحق عرض الموجة الأولى."

📋 خطوات التسجيل:
1. جمع البيانات الأساسية
2. تصوير البطاقة الشخصية
3. تصوير المحل (واجهة + داخلي)
4. إنشاء الحساب
5. تحديد موعد التدريب

🗣️ النص (لو متردد):
"مفيش مشكلة، خد وقتك.
هسيبلك رقمي والبروشور.
بس تفتكر إن العرض ده لأول 30 تاجر بس."
```

### 8. الختام

```
🗣️ النص (بعد التسجيل):
"مبروك! أنت دلوقتي شريك مؤسس في إنجزنا ببني سويف 🎉
هتواصل معاك [اسم المدرب] خلال 48 ساعة للتدريب.
لو عندك أي سؤال، كلمني في أي وقت."

🗣️ النص (بدون تسجيل):
"شكراً على وقتك. لو غيرت رأيك أو عندك أسئلة، كلمني.
ده رقمي [البطاقة]. يوم سعيد!"
```

## نصائح عامة

### افعل ✅

- ابتسم وكن ودوداً
- استمع أكتر ما تتكلم
- استخدم لغة بسيطة
- ركز على التوفير المالي
- اعرض التطبيق عملياً
- احترم وقت التاجر

### لا تفعل ❌

- لا تضغط بشكل مزعج
- لا تتكلم بسرعة
- لا تنتقد المنافسين بشكل مباشر
- لا تعد بأشياء غير مضمونة
- لا تتجاهل اعتراضات التاجر

## الفئات المستهدفة

عند زيارة التجار، ركز على الفئات التالية:

| الفئة                                    | نقاط البيع الرئيسية                   |
| ---------------------------------------- | ------------------------------------- |
| المطاعم (Restaurants)                    | طلبات أكتر، عمولة أقل من المنافسين    |
| الصيدليات (Pharmacies)                   | نظام تسعير مرن، لا حاجة لقائمة منتجات |
| السوبر ماركت (Supermarkets)              | توصيل بسائقك، تسعير لحظي              |
| الخضراوات والفاكهه (Vegetables & Fruits) | تسعير يومي حسب السوق                  |
| البن والحلويات (Coffee & Patisserie)     | قائمة ثابتة مع مرونة للطلبات الخاصة   |
| أكل بيتي (Home-Cooked Food) 🍲           | أكل بيتي طازج، طلبات يومية متنوعة     |

## ملخص بالعربية

### النقاط الرئيسية

- **قبل الزيارة:**
  - مراجعة معلومات التاجر وتجهيز المواد (بروشور، بطاقات، تابلت)
  - معرفة العرض الحالي (الموجة)

- **مراحل المحادثة:**
  1. التحية والتعريف (30 ثانية)
  2. فهم الوضع الحالي (1-2 دقيقة)
  3. تقديم إنجزنا (2-3 دقائق)
  4. عرض الحساب والتوفير (1-2 دقيقة)
  5. عرض التطبيق (2-3 دقائق)
  6. التعامل مع الاعتراضات
  7. إتمام الصفقة
  8. الختام

- **النقاط الرئيسية للبيع:**
  - صفر رسوم تسجيل
  - صفر عمولة أول 30 يوم
  - 7% عمولة فقط (مقابل 18-25% للمنافسين)
  - التوصيل بسائق التاجر الخاص

- **التعامل مع الاعتراضات:**
  - "أنا مع طلبات" → ستوفر أكتر من 50 ألف جنيه سنوياً
  - "التطبيق جديد" → عرض الموجة الأولى للمؤسسين
  - "مش عندي وقت" → موعد آخر أنسب
  - "العمولة كتير" → أقل عمولة في السوق

- **الفئات المستهدفة:** المطاعم، الصيدليات، السوبر ماركت، الخضراوات والفاكهه، البن والحلويات، أكل بيتي
